# Avrupa Fuarlarına Katılan Türk Firmaları

Avrupa'daki büyük ticaret fuarlarına katılan Türk firmalarının fuar fuar listesi (gıda, tekstil, makine, yapı/mobilya/ev).

**Sayfa:** https://beko190.github.io/avrupa-fuar-turk-firmalari/

Kapsanan fuarlar: Fruit Logistica, BIOFACH, Heimtextil, Domotex, Hannover Messe, LIGNA, BAU, ISH, Ambiente.

Kaynak: fuarların resmi katılımcı arama sistemleri, 5 Kasım 2026 itibarıyla. 2027 kayıtları sürdüğü için listeler değişebilir. Hannover Messe, LIGNA ve Domotex için 2027 listesi henüz yayımlanmadığından son edisyonun katılımcıları kullanılmıştır.
